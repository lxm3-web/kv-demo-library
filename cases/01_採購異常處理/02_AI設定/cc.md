# CC 版（Claude Code Agent）— 採購異常處理

> 狀態：**由 Kyo 在本機自建**（2026-09-16），資料走 Google Drive，測完 push GitHub 給同事 sync。本檔只是網頁設計師的設計參考，不是實作。設計原則：同一份資料，一句話，CC 讀完全部、把事做完、交出真的東西。

## 一句話輸入
`AB123 供應商通知延遲 14 天，處理。`

## CC 自己做的事
1. 讀 `01_輸入假資料/` 五張表（或直接讀 Sheet）
2. 算 days_remaining、比安全庫存
3. 撈受影響訂單，依 priority 與 production_date 排序
4. 撈備援供應商，算可補多少、缺口多少、漲幅
5. 對 policy 逐條判定觸發哪些規則、要誰核准
6. 寫 incident_log 一筆

## 交付物（四樣）
| # | 檔案 | 給誰 |
|---|---|---|
| 1 | `異常處理報告_AB123.pdf`（或 .md）：狀況／影響／備援方案／簽核建議 | 採購主管 |
| 2 | `詢價信_CoreSupply.md`、`詢價信_BoardKing.md` | 備援供應商 |
| 3 | `通知_procurement_director.md`（含觸發規則 R003／R004／R006／R009） | 核准主管 |
| 4 | incident_log 新增一列 | 系統 |

| | AI 版（GPTs） | CC 版 |
