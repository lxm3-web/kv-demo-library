# 展示腳本 — 07 客訴分級助理（草稿）

## 開場一句
「早上九點 LINE 跳十二則客訴，你們業務怎麼決定先回哪一則？靠語氣？」

## AI 版（Gem）
| 你貼 | 它回 | 你說 |
|---|---|---|
| 大興通路（6 支異音、明天要出貨） | L2 加急，依據「時間壓力不是損失」，四步回覆 | 「它照作業辦法判，不照語氣。」 |
| 冠捷百貨（語氣平和，「摸起來燙手」） | L4，安全疑慮一律直上，通知品保、停批號 | 「這則靠語氣會被放到下午。」 |
| 群威（這個月第三次） | 開關失靈本是 L2，自動升 L3 | |

收尾：「一則三十秒。但十二則就是貼十二次，順序還是你排。」

## Agent 版
| 你說 | 它做 |
|---|---|
| Enter | 12 則全判、12 份回覆草稿、主管回報、品保通知、處理紀錄、處理順序 |
| 開處理順序 | L4 兩則最上面，標「主管親自接手，業務不要自己回」 |
| `好，發下去` | 六份標已確認 |

收尾：「判級它做、草稿它擬、該報的它報。你只按送出。」
