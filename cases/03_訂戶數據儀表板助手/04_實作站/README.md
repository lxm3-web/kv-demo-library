# 04 實作站 — 兩支本機 HTML（來自課堂教具，去品牌化）

| 檔 | 用途 | demo 怎麼用 |
|---|---|---|
| `資料脫敏器.html` | 本機離線把 Email／姓名／手機變代號，Email 走一致代號跨表可串 | 開瀏覽器 → 拖三張 CSV → 下載去敏版 → 才拿去給 AI |
| `訂閱流失預警儀表板.html` | 讀去敏後的資料，看續訂率、流失預警、分群 | 開瀏覽器 → 載入去敏後的 CSV |

兩支都是單一 HTML、不連網（儀表板內建地圖圖示會嘗試載 unpkg，離線也能用）。網站版放 `lab/03-deid.html`、`lab/03-dashboard.html`。
