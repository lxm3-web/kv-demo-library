# 01 輸入假資料 — 會費對帳催繳助理

> 北區科技產業協會（虛構）2026 年會費。**全部合成**，公司名、聯絡人、Email（example.com）皆虛構。

| 檔 | 筆數 | 內容 |
|---|---|---|
| `會員名冊_2026.csv` | 120 | 會員編號、公司、聯絡人、級別（一般 6,000／贊助 20,000／團體 36,000／理監事 50,000）、年費、應繳期限、聯絡方式 |
| `銀行入帳明細_2026.csv` | 約 100 | 入帳日、交易序號、管道、匯款人名（**故意跟公司全名不一致**：去掉「股份有限公司」、用聯絡人個人名、部分打碼）、金額、備註 |
| `會員名冊_2026_解答.csv` | 120 | 出題者用：每個會員的真實狀態（已繳／未繳／短繳／對不上／重複／久未繳），**不給 AI、不上台** |

對帳的戲：60 已繳、22 未繳、14 短繳（少 500–3,000）、10 匯款人對不上（用個人名匯）、8 重複繳、6 從一二月拖到現在。
催繳分級：逾期 1–29 天提醒 ／ 30–59 天強調 ／ 60 天以上警告；短繳另寫補繳；重複繳要退款或抵明年。
