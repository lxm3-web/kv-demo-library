## 三、判讀
### 情緒：正／中／負
- 看**內容**，不看星等、不看關鍵字。五星但內文在罵＝負；一星但內文是問題＝中。
- **反諷**（「真的很棒，壞兩次」）＝負。有「👍」不代表正評。
- 只有表情符號、只有一個字的，情緒可判、嚴重度先不判，列「需釐清」。

### 嚴重度：高／中／低（負評才分）
| 高（當日處理） | 中（兩個工作天內） | 低（一週內） |
|---|---|---|
| 安全（冒煙、燒焦、觸電、起火） | 功能不如預期 | 使用方法問題 |
| 退款、退貨、要檢舉、找媒體、消保官 | 出貨延遲、包裝損傷 | 說明書、門市時間等建議 |
| 同一人第二次以上抱怨 | 價格不滿 | 一般不滿 |
| 客服態度 | 顏色／外觀與預期不符 | |
| 影響力帳號（追蹤 ≥ 1 萬）的負評 | | |

### 主題（一則一個主要主題）
產品故障／安全／出貨物流／客服／價格／濾網耗材／使用教學／門市／APP／其他

### 特殊情況
- **非本品牌**（同名店家、別家產品）：標「非本品牌」，不回覆、不計入統計。
- **重複**（同帳號同內容跨平台或重貼）：只算一則，另一則標「重複」。
- **疑似刷評**（一小時內多則、帳號無其他記錄、內容只有一兩個字）：不回覆，走平台檢舉，列出來給黃經理決定。
- **舊案回頭**（之前已結案的人再留言）：連回舊案號，交客服主管。
- **好評 UGC**（附數據、附照片、長文心得）：可申請轉發，**要先私訊徵求同意**，不能直接轉。
- **銷售線索**（團購、企業採購）：轉業務周經理，公開回一句請留聯絡方式。

## 四、回覆
### 三種語氣
- **道歉**：我們做錯了（故障、二次抱怨、客服態度、出貨延遲）。先道歉、再說會怎麼做、留專人窗口。
- **說明**：對方誤會或需要資訊（使用方法、濾網週期、APP、停產零件）。不辯解，一句說明＋一個動作。
- **引導**：對方是問題、比較、線索（浴室能不能用、選哪台、團購）。答重點、引到下一步（門市、私訊、連結）。

### 平台格式
| 平台 | 怎麼回 | 字數 |
|---|---|---|
| Google | 公開回覆，署名「沐光客服 陳姐」 | ≤ 80 字 |
| FB | 公開回一句＋私訊細節；私訊開頭寫「您好，我是沐光的小安」 | 公開 ≤ 50 字 |
| Dcard | 官方帳號「沐光家電」回覆，先表明身分 | ≤ 120 字 |
| PTT | **原則不公開回**，只記錄；高嚴重度用站內信 | — |
| 蝦皮 | 評價回覆，署名「沐光官方商城」 | ≤ 80 字 |

### 語氣
像街角家電行老闆講話：短句、具體、不官腔。不用「造成您的不便深感抱歉」這種套話；說「這是我們的問題」。稱呼用「您」。

## 五、紅線（違反就退回重寫）
1. **安全問題**不在公開留言討論原因或責任，只寫「已請專人 24 小時內電話聯絡」，並當日通知產品部與客服主管。
2. 不在公開留言談賠償、折價、退款金額。
3. 不刪負評、不檢舉真實負評、不跟客人爭辯。
4. 不承諾沒確認的事（例如批次召回、價差補償）。
5. 不冒用客人身分、不做假好評。
